## Statement
There are exactly $\lvert B \rvert$ [[Constant Functions|Constant Function]] $f : A \to B$.

## Explanation

## Proof(s)
Suppose that $f : A \to B$ is a [[Constant Function]].\
Then $\exists b \in B$ such that $\forall a \in A, f(a) = b$.\\
Hence we have that there are ${\lvert B \rvert \choose 1} = \lvert B \rvert$ choices for $b$, and hence $\lvert B \rvert$ such functions $f$, as wanted.
