## Statement
Two ordered pairs $(x, y)$ and $(x', y')$ are *equal*, $(x,y) = (x', y')$ iff $x = x'$ and $y = y'$

## Explanation

## Proof(s)
By definition of [[Ordered Pair]]s, $(x, y) = \\{\\{x\\}, \\{x, y\\}\\}$ and $(x', y') = \\{\\{x'\\}, \\{x', y'\\}\\}$.\
Hence we have that $(x,y) = (x', y')$ iff $\\{\\{x\\}, \\{x, y\\}\\} = \\{\\{x'\\}, \\{x', y'\\}\\}$.\
By the [[Axiom of Extensionality]] this is true iff these sets contain the same elements, i.e. if $\\{x\\} = \\{x'\\}$ and $\\{x, y\\} = \\{x', y'\\}$.\
Again, by the [[Axiom of Extensionality]], this is true iff $x = x'$ and $y = y'$, as wanted.
