## Statement
A set $S$ is *countable* if there exists a [[Bijection]] $f : \mathbb{N} \to S$.
If there does not exist such a [[Bijection]] then we say that $S$ is *uncountable*.

The [[Cardinality]] of a countable set is the same as that of the [[Natural Numbers]], denoted $\aleph_0$.
