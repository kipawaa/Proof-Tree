## Statement
There exists exactly one set with no elements.

## Explanation

## Proof(s)
By the [[Axiom of Existence]] we have that there exists a set with no elements.

Suppose that there exist two sets, $A$ and $B$, each with no elements.\
Notice that $A$ and $B$ possess the same elements, and hence by the [[Axiom of Extensionality]] we have that $A = B$, as wanted.
