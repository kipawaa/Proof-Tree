## Statement
A [[Relation]] $R$ is *reflexive* in a set $A$ iff the [[Ordered Pair]] $(a, a)) \in R$ for all $a \in A$.

## Explanation
This means that a [[Relation]] is reflexive in a given set iff every element in that set is related to itself by this relation.
