## Statement
A set $\alpha$ is an *ordinal number* iff $\alpha$ is [[Transitive|Transitive Set]] and [[Well-Ordered]] by $\in \mid_\alpha$, which is membership restricted to the set $\alpha$. Explicitly, $\in_\alpha = \\{(x, y) \in \alpha \times \alpha \mid x \in y\\}$.
