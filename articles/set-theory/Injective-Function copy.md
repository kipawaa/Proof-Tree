## Statement
A [[Function]] $f : A \to B$ is *injective* iff for every $a, a' \in A$ we have that $f(a) = f(a') \implies a = a'$.

## Explanation
This means that each element in the [[Domain|Domain of a Relation]] gets mapped to a unique element in the [[Range|Range of a Relation]].
