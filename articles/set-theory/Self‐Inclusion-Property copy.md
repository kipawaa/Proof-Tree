## Statement
Every set is a subset of itself, i.e. for any set $A, A \subseteq A$.

## Explanation

## Proof(s)
By definition of $A$, forall $x$, if $x \in A$ then $x \in A$.\
Hence by definition of [[Subset]], $A \subseteq A$.
