## Statement
A [[Relation]] $R$ is *symmetric* in a set $A$ iff $(a, b) \in R \implies (b, a) \in R$ for all $a, b \in A$.

## Explanation
This effectively means that a [[Relation]] is symmetric in a set if the order of the elements is irrelevant.
